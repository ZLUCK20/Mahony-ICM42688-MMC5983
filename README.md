# Mahony-ICM42688-MMC5983
使用Mahony互补滤波解析陀螺仪姿态
目前这一版本磁力计校准了，与yaw角度融合在静态表现很好，但动态效果不佳，动态使用是可以通过加权系数减轻或去除磁力计的影响（不用磁力计其实icm42688的yaw角速度纯积分也够用，而且使用的rk4积分，漂移控制的比较好），pitch和roll两个角度和加速度计融合静态动态表现都很好不需要其他任何处理，后续若磁力计问题进行了优化会更新到仓库

代码运行环境为vscode下的stm32扩展，使用的是CMake构建系统，ARM gcc为编译器，详细可以看文件夹中的cubemx配置的.ioc文件

上传文件中的rar压缩包是整个项目的完整包，配置好vscode的stm32环境以后可以直接把解压缩的完整包加入工作区编译运行；另外上传的一些单独文件分别是cubemx配置文件、重要算法代码文件和main.c的调用（方便直接预览），当然直接在vscode里面开完整包更好读代码，建议直接用完整包
